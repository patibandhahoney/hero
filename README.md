# ⚡ Scroll-Driven Hero Animation

A responsive, high-performance hero section built with HTML, CSS, JavaScript, and GSAP ScrollTrigger.

## ✨ Features

* Sticky 100vh hero section with scroll-driven animation.
* Animated headline with neon laser reveal.
* Hypercar movement and glowing energy trail.
* Four animated impact statistics cards.
* Smooth GSAP animations with GPU-accelerated transforms.
* Optional electric car sound effects.

## 🛠️ Technologies

HTML5 • CSS3 • JavaScript • GSAP ScrollTrigger

hero/

Push the project to GitHub and enable GitHub Pages from **Settings → Pages**.
